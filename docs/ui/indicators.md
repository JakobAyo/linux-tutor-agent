# Indicators

A notification per new command gets annoying. Default: a quiet counter of unread cards, e.g. `📘 2`.

- **tmux `status-right`:** `#(linux-tutor count)` refreshed on tmux's status interval.
- **zsh `RPROMPT`:** read a small count file (not a subprocess) so the prompt stays fast.
- **`notify-send`:** optional, off by default.
