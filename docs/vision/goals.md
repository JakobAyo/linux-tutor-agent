# Goals

- **Learn while working.** I use my machine normally. The tutor notices commands, flags, and shell idioms that are new to me and teaches them, with no searching on my side.
- **Discovery, not reference.** A lesson starts from a command I ran, then teaches what I don't know yet: unused flags with use cases, combinations with other commands, related or better tools, and the concept behind it. It should give me new ideas and keep me motivated ([ADR 0009](../decisions/0009-discovery-lessons.md)).
- **Continuous learning.** Commands I keep using get a series of lessons that go deeper each time ([ADR 0010](../decisions/0010-lesson-series-per-command.md)).
- **Commands and mechanisms.** Beyond syntax, build a mental model of the system: systemd units, journald, pacman/AUR, permissions, signals, file descriptors.
- **Remember progress.** Track what I've seen and what I understand, so I'm only taught what's new.
- **Correct facts.** Explanations match the versions installed on my machine (Arch is rolling release).

## Success
- After a few weeks I can explain and reuse commands I used to copy-paste.
- Over months, I become comfortable doing everything in the terminal and write my own scripts and automations.
- I actually open and read the cards (to be checked after the M0 spike week).
