# Concepts

Commands are grouped into the mechanisms behind them, for senior-level understanding beyond syntax.

Candidate concepts: systemd units, journald, pacman / AUR, permissions and ownership, signals and processes, file descriptors and redirection, networking (sockets, ports), filesystems and mounts.

Example: `journalctl`, `systemctl status`, and `dmesg` all lead to "how logging works on systemd systems".
